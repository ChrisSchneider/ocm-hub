# OpenCode base images

Two hardened base images from the openCode community registry, published as
one OCM component so they can be transferred, verified and mirrored together.

| Resource | Image |
| --- | --- |
| `alpine` | `registry.opencode.de/oci-community/images/auswaertiges-amt/alpine:3.24.0` |
| `python3` | `registry.opencode.de/oci-community/images/zendis/python3:3.14-minimal` |

## Get it with OCM

    ocm get cv ghcr.io/chrisschneider//github.com/chrisschneider/opencode-base-images -o widetree

The hub's **Usage** tab shows the exact commands for every version and
location, including verification of the signature.
